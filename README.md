# nutthapat-sumanont.github.io

My personal site: https://nutthapat-sumanont.github.io

I'm Nutthapat (Beck) Sumanont, a BSc student at The University of Hong Kong. The site covers my leukemia work, both at the lab bench (sesamin on NB4 and MOLT-4 cells) and in the data (NPM1-mutated AML in Beat AML 2.0, replicated in TCGA-LAML).

## Files

- `index.html` is the page
- `style.css` holds the styles, with light and dark mode
- `script.js` runs the animations: the scrolling story, the sesamin dose experiment, the therapeutic window chart and the hexagon field
- `photo.jpg` and `og.png` are my photo and the link preview image
- `.nojekyll` tells GitHub Pages to serve the files as they are

Plain HTML, CSS and JavaScript. No build step and no outside libraries.

## Update the site

Edit the files, commit and push to `main`. GitHub Pages republishes in a minute or two.
